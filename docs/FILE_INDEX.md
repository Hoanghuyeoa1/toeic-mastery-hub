## 3. Quy Ước Bổ Sung Khi Thêm/Xóa File Trong Tương Lai

1. Khi tạo thêm bất kỳ component, service, utility hoặc kiểu dữ liệu mới:
   - Ghi lại đường dẫn, vai trò kỹ thuật và xuất khẩu chính vào file này (`docs/FILE_INDEX.md`).
   - Cập nhật số lượng file trong `README.md`.
2. Khi xóa hoặc tái cấu trúc tách file:
   - Cập nhật bảng chỉ mục để xóa hoặc trỏ đúng đường dẫn mới.
   - Ghi chú thay đổi vào `CHANGELOG.md`.
